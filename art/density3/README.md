## 显示与布局

成品直接保存整数 3×3 色块，不使用模糊、锐化或抖色。游戏通过纹理的逻辑尺寸覆盖保持原来的位置和交互尺寸，上传完整物理纹理供渲染。1440p 下主要美术显示为 3px；其他窗口分辨率会随游戏整体缩放。小头像为保证可读性使用更细的采样，不强制把嘴眼缩成一个大格。

人物及桌台轮廓关闭，即使旧设置曾开启描边也不会重新加上。42 个商品的旧紧裁切框略有扩展，以保留新的轮廓边缘；每项原框、新框和额外保留像素见 `import-report.json`。其他逻辑尺寸保持原基准。

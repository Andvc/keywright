# Keywright: art inventory

Every picture the game needs, generated from `art/tools/build_manifest.py` (edit there, not here). The full spec and the assembled prompt for each asset are in `art/manifest.json`; the shared style is `art/ART_DIRECTION.md`.

Priorities: **P1** replaces something the game shows today; **P2** replaces a code-drawn stand-in or adds polish the game is ready for; **P3** is new (story scenes, extra portraits, store art) and needs code to use it.

Round 2 (0.25) redraws every category marked *redraw*, quieter, in batches 9 (its anchors) to 15; the chest is drawn in code now (`tools/custom_art.py`) and isn't listed. See `art/README.md`.

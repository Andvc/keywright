# Keywright: art inventory

Every picture the game needs, generated from `art/tools/build_manifest.py` (edit there, not here). The full spec and the assembled prompt for each asset are in `art/manifest.json`; the shared style is `art/ART_DIRECTION.md`, and the shop scene's layout `art/tools/scene.py`.

Priorities: **P1** the game needs it; **P2** polish the game is ready for; **P3** new, and needs code to use it.

Round 2 (0.25) redraws every category marked *redraw*, flat and quiet, in batches 9 (its anchors) to 15, and builds the shop scene from layers: a sky for each time of day, and for each shop the place, its frame, shelf, counter, appraisal sheet and lanterns, with props for what you've bought and full-length figures for everyone at the counter. The chest is drawn in code (`tools/custom_art.py`). See `art/README.md`.
